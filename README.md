# Maratona Java — Virado no Jiraya (DevDojo)

Repositório com os exercícios e projetos práticos desenvolvidos durante o curso **Maratona Java** da DevDojo, organizados por bloco de conteúdo.

## 📚 Sobre

Cada pasta representa um bloco de aulas do curso, com um projeto prático que aplica os conceitos estudados naquele trecho. A ideia é mostrar a evolução do aprendizado, do básico até tópicos mais avançados como concorrência e JDBC.
